# DIT University PYQ Portal (Frontend)

This is the frontend client for the DIT University Previous Year Question Papers (PYQ) portal. It allows students to browse, search, and view question papers uploaded by administrators.

## Features
- **Browse Papers**: Organized by course, year, and subject.
- **PDF Viewer**: Integrated secure PDF viewer for exam papers.
- **Admin Dashboard**: Upload and manage papers (restricted access).
- **Responsive Design**: Works on mobile and desktop.

## Tech Stack
- **Framework**: Standard HTML/JS with ES Modules (Vite-like structure)
- **Styling**: Core CSS + Responsive Layouts
- **Baas**: Firebase (Auth, Storage)

## Setup & Run
1.  Clone the repository.
2.  Install dependencies (if any): `npm install`
3.  Run locally: `npm run dev` (or use Live Server)

## Configuration
Environment variables are securely stored in `.env`.
Authentication and Database connections are handled via Firebase.
